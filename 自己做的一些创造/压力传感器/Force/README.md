# 压力报警系统代码与使用手册

## 1. 系统概述
- MCU: STM32F10x，外接 HX711 压力/称重模块。
- 显示: OLED 显示当前重量 `W:` 以及报警阈值/编辑值 `T:` / `E:`。
- 报警: 蜂鸣器 + PC13 指示灯（低电平点亮），超阈值声光提示，可按键静音/消警。
- 按键: 4×4 矩阵键盘，行接 PB8~PB11（行1~行4），列接 PB12~PB15（列1~列4）。

## 2. 主要文件
- `Hardware/Key.h` / `Hardware/Key.c`: 矩阵键扫描、按键码定义。
- `APP/system.c`: 主循环、阈值设定、开机去皮/滤波、报警处理。
- `Hardware/HX711.c`: 采样、去皮、标定系数设置。
- `Hardware/Buzzer.c`: 蜂鸣器与 PC13 LED 控制。

## 3. 按键功能映射（行/列编号）
- 数字键：
  - 行1列1=1，行1列2=2，行1列3=3
  - 行2列1=4，行2列2=5，行2列3=6
  - 行3列1=7，行3列2=8，行3列3=9
  - 行4列2=0
- 功能键：
  - 行1列4：进入/清空阈值输入（显示前缀变为 `E:`）
  - 行2列4：确认阈值输入并生效（显示回 `T:`）
  - 行3列4：阈值增加 10g
  - 行4列4：阈值减少 10g
  - 行4列3：报警使能开/关（若正在输入，会先提交输入）
  - 行4列1：消警/静音当前报警（任何按键都会先静音，这个是专用快捷键）

## 4. 典型使用流程
1) 上电：自动空载去皮（多次采样求均值）并初始化滤波；蜂鸣器短响，PC13 闪烁三次。
2) 查看重量：OLED 第2行 `W:` 后显示当前重量（滤波值）。
3) 设置阈值（直接输入）：按行1列4 → 输入数字（最多4位）→ 按行2列4 确认，阈值生效，显示回 `T:`。
4) 微调阈值：按行3列4 每次 +10g，或行4列4 每次 -10g（在编辑状态会先提交输入）。
5) 报警开关：按行4列3 切换使能；关闭后不报警但继续显示重量。
6) 消警静音：任何键都会先静音，行4列1 可快速消警。

## 5. 报警逻辑
- 超过阈值：蜂鸣器+PC13 快速闪烁/短促鸣叫（20ms 脉冲），循环检测；若被按键静音则保持静音，直到重量跌回阈值减去 10g 后再超限才重新报警。
- 低于复位阈值（阈值-10g）：自动解除静音，准备下一次报警。

## 6. 开机校准与滤波
- 上电去皮：采样 40 次取平均，空载为 0g。
- 滤波预充：20 次样本求均值初始化；运行中使用一阶低通（系数 0.5）。
- 如需更平滑或更灵敏，可调整 `FILTER_ALPHA`。

## 7. 常见操作
- 清零阈值：行1列4 → `0` → 行2列4。
- 恢复默认 340g：行1列4 → `340` → 行2列4，或用行3列4/行4列4 微调至 340。
- 按键不灵敏：当前去抖 3ms，扫描周期 50ms；可继续减小去抖或提高扫描频率。

## 8. 编译与下载
用 Keil/MDK 打开 `Project.uvprojx` 全编译后下载。确保行线 PB8、PB9、PB10、PB11 依次连接行1~行4，列线 PB12、PB13、PB14、PB15 依次连接列1~列4，列端使用下拉。

## 9. 可调宏
- `THRESH_STEP_G`：阈值微调步长（默认 10g）。
- `RESET_GAP_G`：报警复位回差（默认 10g）。
- `ZERO_CAL_SAMPLES`、`FILTER_PRIME_NUM`：开机去皮和滤波初始化采样次数。
- `FILTER_ALPHA`：运行时低通滤波系数，越小越平滑。
